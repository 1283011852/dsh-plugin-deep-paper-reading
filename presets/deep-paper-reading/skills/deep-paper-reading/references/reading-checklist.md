# Deep Reading Checklist

> 深度阅读过程中必须逐项核对的清单。每完成一项打 ✅，不允许跳项。
> 此清单与 SKILL.md 中的 Core Workflow 7 个 Phase 一一对应。

---

## Phase 1: 论文获取与初步扫描

- [ ] 论文全文已获取（PDF 或 HTML 全文）
- [ ] 补充材料已获取（如有提及但无法获取，记录"缺失"）
- [ ] 已阅读 Title + Abstract，能用一句话说出核心发现
- [ ] 已阅读 Introduction 末段，明确研究假设/科学问题
- [ ] 已浏览所有主图标题和图注（不看正文），获得视觉故事线
- [ ] 已阅读 Discussion 第一段（作者自述的主要发现）
- [ ] 已浏览 Results 所有小标题，理解实验结构
- [ ] 已识别论文类型（原始研究/方法学/简报/综述）
- [ ] 已记录基本元数据（作者/期刊/年份/DOI/基金/COI）

## Phase 2: 正文精读

### Introduction
- [ ] 已提取研究背景（论文引用的关键前人工作）
- [ ] 已明确知识空白 (knowledge gap)
- [ ] 已精确定义核心假说/研究问题
- [ ] 已评估假说的重要性（如果正确意味着什么？）

### Results（逐段）
- [ ] 每一段都找到了其对应的图表
- [ ] 对每一段：确认正文是否准确反映了图表数据
- [ ] 标记了所有"data not shown"的位置
- [ ] 标记了正文与图表数据不一致的地方
- [ ] 记录了所有报告的具体统计值（p 值、效应量等）

### Discussion
- [ ] 已提取作者对每个关键发现的解读
- [ ] 已识别作者承认的局限性
- [ ] 已识别作者未讨论的明显局限性
- [ ] 已提取作者提出的未来实验方向
- [ ] 已评估结论是否被数据支持的力度

### Methods
- [ ] 已通过方法章节定位每个实验的技术细节
- [ ] 已提取完整实验方案（关键试剂、仪器、条件、n 值、统计方法）
- [ ] 已识别统计方法（已检查是否适用于数据类型）

## Phase 3: 补充材料精读

- [ ] 已读取所有补充图表
- [ ] 已读取所有补充表格
- [ ] 已读取补充方法/方案
- [ ] 每个补充图表都找到了其正文引用位置
- [ ] 标记了放在补充材料中的关键数据（为什么不在正文？）
- [ ] 评估了补充材料的完整性和质量

## Phase 4: 图注-正文对应

- [ ] 每个主图 (>0 个) 都有对应表条目
- [ ] 每个补充图都有对应表条目
- [ ] 每个图注都独立阅读后再与正文比对
- [ ] 每个图都标记了一致性评估（✅一致 / ⚠️过度解读 / ❌矛盾）
- [ ] 标记了正文声称但图中看不出的结果
- [ ] 标记了正文淡化的图中明显数据

## Phase 5: 逐实验拆解

- [ ] 每个独立实验都有四要素拆解
- [ ] 每个实验的"目的"都已明确（为什么做？）
- [ ] 每个实验的"设计与工具"都已完整记录（做了什么？怎么做的？用什么？）
  - [ ] 模型系统已记录
  - [ ] 实验分组已记录
  - [ ] 关键试剂和仪器已记录
  - [ ] 对照设计已评估
  - [ ] n 值和重复水平已记录
  - [ ] 统计方法已记录
- [ ] 每个实验的"结果"都已详细描述（拿到了什么？具体数据？）
- [ ] 每个实验的"解读"包含:
  - [ ] 作者的解读
  - [ ] 数据→解读的论证强度评估
  - [ ] 替代解释
  - [ ] 确认所需的额外实验
  - [ ] 逻辑链中的位置

## Phase 6: 逻辑链重建

- [ ] 已绘制完整逻辑流程图（背景 → 空白 → 假说 → 实验 → 结果 → 解释 → ... → 结论）
- [ ] 已分析每个实验间过渡的逻辑关系类型
- [ ] 已标记逻辑链中的断裂点/跳跃
- [ ] 已识别所有从相关性数据推断因果性的地方
- [ ] 已识别所有从模型系统到人类疾病的逻辑跳跃
- [ ] 已评估总体逻辑链强度（严谨/一般/存在重大跳跃）

## Phase 7: 报告输出

- [ ] 报告包含所有 8 个必需章节
- [ ] 论文概览完整填写
- [ ] 逻辑链章节有完整的流程图和过渡分析
- [ ] 图注-正文对应表覆盖所有图表
- [ ] 每个实验有完整的四要素拆解
- [ ] 补充材料已独立分析
- [ ] 方法与统计已评估
- [ ] 批判性评读包含优势、局限、差距分析、替代假说
- [ ] 关键术语表足够完整（领域外人也能看懂报告）
- [ ] 报告使用用户的语言（中文用户 → 中文报告）
- [ ] 报告可以独立阅读（不需查原文即可理解）
