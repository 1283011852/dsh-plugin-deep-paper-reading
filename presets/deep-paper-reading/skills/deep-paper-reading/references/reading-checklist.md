# Deep Reading Checklist

> 深度阅读过程中必须逐项核对的清单。每完成一项打 ✅，不允许跳项。
> 此清单与 SKILL.md 中的 Core Workflow 8 个 Phase 一一对应。
> Phase 7（可视化）与 Phase 8（报告输出）是**交付关卡**：这两节未全绿，报告就不算完成。

---

## Phase 1: 论文获取与初步扫描

- [ ] 论文全文已获取（PDF 或 HTML 全文）
- [ ] 全文已落盘为 `sources/paper-fulltext.txt`（可复核引文）
- [ ] 补充材料已获取（如有提及但无法获取，记录"缺失"）
- [ ] 已阅读 Title + Abstract，能用一句话说出核心发现
- [ ] 已阅读 Introduction 末段，明确研究假设/科学问题
- [ ] 已浏览所有主图标题和图注（不看正文），获得视觉故事线
- [ ] 已把图版渲染成图片并看过（不是只看图注）
- [ ] 已阅读 Discussion 第一段（作者自述的主要发现）
- [ ] 已浏览 Results 所有小标题，理解实验结构
- [ ] 已识别论文类型（原始研究/方法学/简报/综述）
- [ ] 已记录基本元数据（作者/期刊/年份/DOI/基金/COI）
- [ ] 已记录**实际达到的证据等级**（全文/摘要级/部分缺失）

## Phase 2: 正文精读

### Introduction
- [ ] 已提取研究背景（论文引用的关键前人工作）
- [ ] 已明确知识空白 (knowledge gap)
- [ ] 已精确定义核心假说/研究问题
- [ ] 已评估假说的重要性（如果正确意味着什么？）

### Results（逐段）
- [ ] 每一段都找到了其对应的图表
- [ ] 对每一段：确认正文是否准确反映了图表数据
- [ ] 标记了所有"data not shown"的位置
- [ ] 标记了正文与图表数据不一致的地方
- [ ] 记录了所有报告的具体统计值（p 值、效应量等）

### Discussion
- [ ] 已提取作者对每个关键发现的解读
- [ ] 已识别作者承认的局限性
- [ ] 已识别作者未讨论的明显局限性
- [ ] 已提取作者提出的未来实验方向
- [ ] 已评估结论是否被数据支持的力度

### Methods
- [ ] 已通过方法章节定位每个实验的技术细节
- [ ] 已提取完整实验方案（关键试剂、仪器、条件、n 值、统计方法）
- [ ] 已识别统计方法（已检查是否适用于数据类型）

## Phase 3: 补充材料精读

- [ ] 已读取所有补充图表
- [ ] 已读取所有补充表格
- [ ] 已读取补充方法/方案
- [ ] 每个补充图表都找到了其正文引用位置
- [ ] 标记了放在补充材料中的关键数据（为什么不在正文？）
- [ ] 评估了补充材料的完整性和质量
- [ ] 未获取的条目已标记为「缺失（正文引用但未获取）」

## Phase 4: 图注-正文对应

- [ ] 每个主图 (>0 个) 都有对应表条目
- [ ] 每个补充图都有对应表条目
- [ ] 每个图注都独立阅读后再与正文比对
- [ ] 每个图都标记了一致性评估（✅一致 / ⚠️过度解读 / ❌矛盾）
- [ ] 每个判断都注明依据是「看图」还是「仅看图注」
- [ ] 标记了正文声称但图中看不出的结果
- [ ] 标记了正文淡化的图中明显数据
- [ ] 已产出图 V3（正文↔图 二分图）与图 V4（一致性矩阵）

## Phase 5: 逐实验拆解

- [ ] 每个独立实验都有四要素拆解
- [ ] 每个实验的"目的"都已明确（为什么做？）
- [ ] 每个实验的"设计与工具"都已完整记录（做了什么？怎么做的？用什么？）
  - [ ] 模型系统已记录
  - [ ] 实验分组已记录
  - [ ] 关键试剂和仪器已记录
  - [ ] 对照设计已评估
  - [ ] n 值和重复水平已记录
  - [ ] 统计方法已记录
- [ ] 每个实验的"结果"都已详细描述（拿到了什么？具体数据？）
- [ ] 每个实验的"解读"包含:
  - [ ] 作者的解读
  - [ ] 数据→解读的论证强度评估
  - [ ] 替代解释
  - [ ] 确认所需的额外实验
  - [ ] 逻辑链中的位置
- [ ] 已产出图 V5（实验证据强度总览）

## Phase 6: 逻辑链重建

- [ ] 已重建完整逻辑链（背景 → 空白 → 假说 → 实验 → 结果 → 解释 → ... → 结论）
- [ ] 已分析每个实验间过渡的逻辑关系类型（排除/扩展/机制/应用/验证）
- [ ] 已标记逻辑链中的断裂点/跳跃
- [ ] 已识别所有从相关性数据推断因果性的地方
- [ ] 已识别所有从模型系统到人类疾病的逻辑跳跃
- [ ] 已评估总体逻辑链强度（严谨/一般/存在重大跳跃）
- [ ] **没有**用文字框图或缩进文字树替代图 V1（文字骨架只能是草稿）

## Phase 7: 可视化构建（交付关卡）

- [ ] 已读 `references/visualization-spec.md` 并按其 V 编号执行
- [ ] 已跑 `python scripts/render-diagram.py --selftest`（首次使用）
- [ ] 必做图 V1–V8 全部产出 PNG
- [ ] 条件图已判定：V9（替代解释存在？）/ V10（临床或队列？）——做了，或写清为何不适用
- [ ] 每张图都有 `source` 行，且能指到具体图号/段落/表号
- [ ] 每张图都有三行图注（说明 / 缺口 / 来源+渲染档）
- [ ] 每张图的 PNG 宽度 ≥ 1200 px，文件名为 ASCII
- [ ] 图里的中文是**真汉字**（不是方框）
- [ ] V1 的虚线边非空，且与过渡表的「V1 边型」列一致
- [ ] 每张图都有 Mermaid 源码或 JSON spec，落在 `figures/` 或附录
- [ ] Mermaid 图都有 `accTitle` + `accDescr`
- [ ] 未渲染的图写明了「图形未渲染（原因）」，没有留空占位符
- [ ] 灰度打印可读（去色后靠字形与线型仍可区分）
- [ ] 报告正文在每张图前都有一句「这张图回答什么」

## Phase 8: 报告输出

- [ ] 报告包含所有必需章节（一至八 + 附录 A/B）
- [ ] 论文概览完整填写，含证据等级声明
- [ ] 逻辑链章节有图 V1/V2 + 过渡表 + 断裂点表
- [ ] 图注-正文对应表覆盖所有图表，且配 V3/V4
- [ ] 每个实验有完整的四要素拆解，且配 V5
- [ ] 补充材料已独立分析，缺失项可见
- [ ] 方法与统计已评估
- [ ] 批判性评读包含优势、局限、差距分析（V6/V7）、替代假说（V9）
- [ ] 关键术语表足够完整（领域外人也能看懂报告），且配 V8
- [ ] 附录 A 图形清单逐行填满（像素/档位/是否完整）
- [ ] 附录 B 收录全部 Mermaid 源码或 spec
- [ ] 报告使用用户的语言（中文用户 → 中文报告）
- [ ] 模板里所有 `[...]` 占位符已替换（可用 grep 自查）
- [ ] 报告可以独立阅读（不需查原文即可理解）

### Phase 8b: 若要求 Word/DOCX

- [ ] 已按 `references/docx-conversion-standard.md` 执行（不是"参考一下"）
- [ ] 页面/样式/表格列数/图注格式符合标准第 2–6 节
- [ ] 已转 PDF 逐页目视复核（字体回退、表格溢出、图片模糊、提示框是否存活）
- [ ] 交付前已确认文件存在，并报出路径、字节数、页数、已渲染/未渲染图清单
